# JMIN Portfolio

개인 포트폴리오 사이트입니다.

## 구성
- 이력 / 경력: Experience, Education, Activities
- 자격증 / 수상경력 / Skills
- 엔트리 프로젝트
- 바이브코딩 프로젝트
- GitHub 기반 지속 업데이트

## 확장 구조
프로젝트 파일을 받으면 다음 구조로 확장할 수 있습니다.

```
/
├─ index.html
├─ README.md
├─ projects/
│  ├─ entry/
│  └─ vibe/
└─ assets/
   ├─ images/
   └─ files/
```

프로젝트마다 상세 페이지, 이미지, 실행 링크, GitHub 소스 링크를 연결할 수 있습니다.
